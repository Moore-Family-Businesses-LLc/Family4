Security posture

Private because of how it is built

Not a marketing promise — these are the mechanisms in the codebase.

🔑 Hardware-backed keys

Message keys are generated and held in the Android Keystore, so they never appear in app memory as raw material you could dump.

🔒 Encrypted at rest

Chat rows store ciphertext and an IV. A stolen database file yields [encrypted], not conversations.

📡 Encrypted in transit

Push-to-talk audio packets are encrypted before they hit the socket, whether they travel over your LAN or a TURN relay.

#️⃣ Hashed app PIN

The unlock PIN is stored as a PBKDF2-HMAC-SHA256 digest with a per-PIN salt and 120,000 iterations — never in plaintext.

🗑️ Retention you control

Pick 7, 30 or 90 days and older messages are swept from the database. "Clear history" actually deletes rows.

🚫 No third-party analytics

No ad SDKs, no behavioural tracking, no data brokerage. The backup destination is your own Drive folder.

Setup

Running in about five minutes

No account, no onboarding funnel. Install the APK, add your people, pick a radio channel.

Download the build

Grab the latest app-debug.apk from the Releases page on any Android 13+ phone.

Allow the install

Android will ask permission to install from your browser or file manager. Approve it once — this is standard for apps outside the Play Store.

Add your family

Open Chat, tap the add button, and enter each member. Everyone installs the same APK on their own phone.

Pick a channel

In Settings choose a walkie-talkie channel between 1 and 99 and share it with the household. That is the whole setup.

Installing over ADB

If you would rather push the build from a computer with USB debugging enabled:

adb install -r app-debug.apk
adb shell am start -n com.family4.app.debug/com.family4.app.ui.splash.SplashActivity

Building it yourself

Clone the repository, add your own API keys to local.properties, then:

git clone https://github.com/Moore-Family-Businesses-LLc/Family4.git cd Family4 ./gradlew assembleDebug

Questions

Frequently asked

Is Family4 available on the Play Store?

Not yet. The current build is a debug APK you can install directly. A signed release and a Play Store listing are on the roadmap.

Which Android versions are supported?

Android 13 (API 33) and newer, built against the Android 15 SDK. It is developed and tested on a Pixel 10 Pro XL.

Where is my family's data stored?

On your devices, in a local encrypted database. Optional backup goes to a folder in your own Google Drive account. There is no Family4 server holding your messages.

Does the walkie-talkie use my minutes?

No. It uses your data connection or local network — the audio streams as UDP packets, relayed through a TURN server when devices can't reach each other directly.

Can I use it with only part of my family?

Yes. Members are added individually, and location sharing is per device — anyone can turn theirs off without affecting the rest.

Is the source code available?

The repository is on GitHub. It is a family project, so expect a fast-moving main branch rather than a polished release cadence.
