Security by design

Six layers, zero compromises

Family data never leaves your device in plaintext and is never sold to an ad network, data broker, or analytics vendor.

🔑 PIN + Biometric lock

AES-256 PIN enforced on every app resume. Optional BiometricPrompt Class 3 authentication. PIN stored only in Android Keystore — never in Room.

🔒 Message encryption

AES-256-GCM for every message. Encryption key lives in the Android Keystore hardware security module, never in the database or SharedPreferences.

🕵️ Stealth mode

Full calculator disguise. A secret tap sequence reveals the real app. A 14-day rotation reminder prevents pattern recognition.

☁️ Encrypted tokens

OAuth tokens (BlueLink, Drive) stored in EncryptedSharedPreferences — AES256-SIV key encryption + AES256-GCM value encryption via Android Keystore.

📦 ProGuard + R8

Release builds use full minification, resource shrinking, and name obfuscation. Source-file attributes kept only for crash symbolication.

🚫 Zero third-party analytics

No Firebase Analytics data is sent to ad networks. No Crashlytics, no Segment, no Amplitude, no Facebook SDK, no data brokers.

Get it running

Build & install in four steps

Clone

Clone fresh-main — the primary development branch.

git clone https://github.com/Moore-Family-Businesses-LLc/Family4.git cd Family4 && git checkout fresh-main

Configure

Add API keys to local.properties (optional — app works without them).

MAPS_API_KEY=your_maps_key GEMINI_API_KEY=your_gemini_key BLUELINK_CLIENT_ID=your_bluelink_id

Build

Build the debug APK with Gradle. Requires JDK 17+ and Android SDK 35.

./gradlew assembleDebug

Install

Install on a connected Android 13+ device via ADB.

adb install -r app/build/outputs/apk/debug/app-debug.apk

FAQ

Common questions

Is Family4 available on the Play Store?

Not yet — the app is in active development. Download the latest debug APK from the GitHub Releases page. A signed release build is available when keystore credentials are configured in local.properties.

Does the app require an internet connection?

No. Family4 is local-first — all data is stored in a local Room database. Features that need the network (maps, AI assistant, BlueLink) degrade gracefully when offline.

Who can see my family's location?

Nobody outside your family group. Location data never leaves the device unless you explicitly share it. There is no server-side storage of location data.

What is the OBD-II vehicle feature?

Connect an ELM327 Bluetooth adapter to your car's OBD-II port. Family4 will poll live engine data (RPM, speed, coolant temp, fuel level, and 13 more) and log trip history. The Hyundai BlueLink integration shows door lock status, tire pressure and remote commands — requires a developer.hyundai.com API key.

Does Health Connect work on all Android 13+ devices?

Health Connect is built into Android 14+ and available as a separate Play Store app on Android 13. If it's not installed, Family4 falls back to demo data gracefully. Permissions are requested at runtime via the standard PermissionController contract.

How do I use Android Auto?

Family4 registers a CarAppService with the POI category. Connect your phone to Android Auto and Family4 will appear. The current Auto UI shows a dashboard screen, a family members list, and a chat messages screen — all built with Car App Library 1.4 ListTemplate screens.
